# 美客多侵权词查询工具（Mercado Libre Risk Checker）

面向中国跨境电商卖家、美客多墨西哥站卖家的侵权与违规自查工具（单页 HTML，无需服务器，免费托管于 GitHub Pages）。

## 功能

- **侵权词搜索**：37 条西语风险词条，按中文/西语/替代写法搜索
- **风险等级筛选**：高风险 / 中风险 / 注意三级 + 六种类型筛选
- **标题描述检测**：粘贴标题或描述，本地匹配高风险词（不上传数据）；支持西语和英语标题识别，词条卡片附英文对照
- **商品图片识别**：上传商品图或粘贴图片链接，浏览器本地 OCR（西语+英语）提取图中文字后自动检测；纯 logo/卡通形象无文字时识别不出，页面会提醒人工对照自查清单
- **商品链接检测**：粘贴美客多商品链接，自动识别商品并检测（官方接口需授权时先按链接中的标题文字检测，并提示粘贴描述查全文）
- **CSV 导出**：一键下载完整词表
- **打印 / 存 PDF**：带打印样式
- **手机适配**：响应式布局 + 深色模式

## 文件

- `index.html` — 网站主页（GitHub Pages 入口）
- `美客多侵权词.html` — 原始文件，与 `index.html` 内容完全相同，保留备份

## 说明

本页词表是依据美客多官方规则与卖家指南整理的风险合成表，不是官方黑名单，仅供卖家自查参考，不构成法律意见。数据调研日期：2026-11-08。
